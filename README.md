1. 项目简介
本项目为逆向工程学习靶场（Reverse Engineering Training Lab），包含自主编译的 Windows EXE 练习程序，仅供网络安全、逆向工程爱好者及在校学生用于合法合规的技术学习、研究、练习。
项目所有资源均为原创编写，无恶意代码、无后门、无窃取用户数据行为，仅用于逆向分析、脱壳、反编译、用于破解、绕过验证、学习等安全技术实训。
